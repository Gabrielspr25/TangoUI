# Sistema Claro

Sistema de gestión empresarial con interfaz moderna y agentes JavaScript internos.

## 🚀 Tecnologías

- **Frontend:** Vite + React + Tailwind CSS
- **Agentes:** JavaScript internos modulares
- **Arquitectura:** Preparado para escalabilidad

## 📋 Módulos del Sistema

- **Gestión** - AgenteGestion
- **Ventas** - AgenteVentas  
- **Caja** - AgenteCaja
- **Contratos** - AgenteContratos
- **Reportes** - Dashboard y métricas

## 🛠️ Instalación

```bash
# Clonar repositorio
git clone https://github.com/Gabrielspr25/sistema-claro.git

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

## 🌐 Desarrollo

```bash
# Servidor de desarrollo
http://localhost:5173/

# Build para producción
npm run build

# Preview de producción
npm run preview
```
